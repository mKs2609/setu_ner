# Data licences

The MIT licence in [`LICENSE`](LICENSE) covers this project's own source
code. It does not relicense the data the project uses, each of which keeps
its own terms.

| Source | Terms |
|---|---|
| **OpenStreetMap**-derived data — road graph, district boundaries, gazetteer | © OpenStreetMap contributors, [Open Database License (ODbL) 1.0](https://www.openstreetmap.org/copyright). Derived databases distributed with this project carry that licence |
| **ASDMA DRIMS** flood reports | Public Government of Assam documents |
| **NASA GPM IMERG** precipitation | NASA open data |
| **Copernicus DEM** elevation | Copernicus open data |
| **CARTO** basemap tiles | © CARTO, used under their basemap terms, attributed in the map |
| **NASA GIBS** imagery | NASA open data, public domain |

The attribution shown to users is in the map footer and in the attribution
table in [`README.md`](README.md).

> This file exists separately from `LICENSE` so that GitHub can detect the
> project's own licence as MIT. Appending anything to `LICENSE` defeats that
> detection, and the repository then shows no licence at all.
