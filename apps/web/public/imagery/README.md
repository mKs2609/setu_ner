A true-colour image of the corridor on 1 June 2025, the day it flooded, was
tried here and removed: it is solid cloud, which is true and unreadable. The
point it was making is now made by `FloodOnsetChart`, which draws the
rainfall and the report for those same days — the data that existed when the
picture did not.

No stock photography is used anywhere in this project. A photograph of
someone else's flood standing in for Assam would misrepresent the thing the
rest of the system is careful about.
